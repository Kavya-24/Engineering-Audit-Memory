### How it works
On a set cadence, loads all the slack, notion, github (code + PR Review) data, jira data in the time window and collate them in the form of projects, notable_highlights with artifacts, updates and continues to append.

### How to Use

1. Go to https://claude.ai/code/routines / https://chatgpt.com/scheduled
2. Attach your source (Slack, Notion, whatever is supported)
3. Copy the ROUTINE.md file (edit according to your needs) AND ENRICH your variables ( username, email, repositories of interest)
4. Ensure that you have google-drive folder set up / ( you could switch to any other data tracking tool really tbh)
